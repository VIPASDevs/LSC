READ THIS BEFORE USING
======

- This calculator has it's core logic split to different files for easier debugging, changing, and usage

- Do not divide by zero because it will crash the program, though doing 0 divided by <> will result in zero

- This is a remake (not a fork as I am the original and current publisher of the code) of Py-Cal and Community Calculator

- to compile, type "*javac*" then the filenames, to create classes. If they are the only class files, type "*jar cfe <whatever>.jar <the current edition the code file is on [as this is written, BETA]> *class*"
    but if it is not. Then type "*jar cfe <whatever>.jar*" then include all the related classes
    then type "*java -jar <whatever>*" to run it. Or double/single click it off your preferences.^^
